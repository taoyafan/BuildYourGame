# 一体化人物素材

状态：10 人、每人 5 种表情的制作稿，等待协调方视觉审核，未接入程序。

## 当前问题

- 同一行的整体造型一致，但源图笔触与衣纹有细微重绘差异；刚性配准后外轮廓边缘最大差异为 3 像素，不能声称逐像素稳定。
- neutral 与 tired 部分嘴角略下垂，需审核是否符合平嘴预期。
- 工位联系表的桌面与电脑是遮挡示意，不是 A2 场景资源。

## 资源与索引

- [人物清单](manifest.json)：m01–m05 男性、f01–f05 女性。每个人的五种表情均为 256×256 RGBA 完整人物 PNG，不做运行时部件拼合。
- [72 像素头像联系表](contact-avatars-72.png)、[工位联系表](contact-workstations.png)、[完整图联系表](contact-full.png)。头像裁自同一人物的 portrait，矩形在清单中登记；联系表同时展示全部五态供审查。
- [检查数据](checks.json)：每行保留一个等比例缩放，不拉伸解剖结构；每格只平移校正横向中心与桌面线。每行五态共用固定桌面 y=240。头顶为 y≈16，实际发型轮廓可有 1–3 像素偏差。
- [原始图集](sources/)、[生成提示词](prompts.md)。两张原图均为 5×5，男性与女性源图分别读取。

## 使用

按清单读取人物 ID 与状态，不按文件顺序猜测性别。表情列固定为 neutral（工作平嘴）、portrait（照片微笑）、tired（半睁疲惫）、blink（闭眼平嘴）、idle（笑眼微笑）。工位沿桌面锚点统一缩放整图；头像使用 portrait 和 avatarRect。运行时切换整张图片，头发、衣服与五官均在图片内。

export-atlases.py 是生产导出脚本，负责切格、清除低透明噪点和游离小斑点、等比例配准、资源索引及联系表。此目录不包含游戏代码或持久测试文件。
