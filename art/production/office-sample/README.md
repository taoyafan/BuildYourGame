## 组合与交互

- 房间、墙面道具、椅子、人物、桌面、电脑分别摆放。桌面遮挡人物腰腿，保留头肩与必要的手部动作；先保证小尺寸下轮廓清楚。
- 一套工位复用为空位或有人状态；样板人物先覆盖一名员工，其余角色保留现有外观。人物头像与自定义外观数据由程序保留。
- 待机轻呼吸由程序驱动，工作使用四帧轻微手部与眨眼循环。暂停和后台切换由程序统一管理。
- 大屏内容、星级、成就数量、状态标记、全部文字与数据由程序叠加；大屏、日历、成就、星级与工位入口各自可用，教程高亮仍指向相应对象。
