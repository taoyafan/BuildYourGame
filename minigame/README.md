# 日光工作室 · 微信小游戏版

本目录是《日光工作室》（BuildYourGame）的微信小游戏移植版，与仓库根目录的网页版共享同一套经营逻辑。

## 目录结构

```
minigame/
├── game.js                小游戏入口（require ui.js）
├── game.json              小游戏配置（竖屏、隐藏状态栏）
├── project.config.json    开发者工具项目配置（appid 待替换）
├── README.md              本文件
└── js/
    ├── core.js            纯逻辑层：game.js 原样复制，零 DOM，CommonJS
    ├── content.js         内容模型层：菜单内容生成（移植自 app.js，零绘制代码）
    └── ui.js              UI 框架层：canvas 渲染、触摸命中、弹窗菜单、存档、游戏循环
```

分层原则：

- `core.js` 与根目录 `game.js` 保持相同的经营逻辑；
- `content.js` 只产出数据（文本、条目、按钮），不知道 canvas 的存在；
- `ui.js` 只负责绘制与交互，不含任何业务规则。

## 本地自测

按需在微信开发者工具或真机中试玩验证，重点见下文「真机验证重点」。遵循根目录 [开发与验证约定](../README.md#开发与验证约定)：不保留自动化测试文件；确需脚本验证时，使用临时文件，验证结束后删除，不提交测试脚本、专用依赖或产物。

## 在开发者工具中运行

1. 打开微信开发者工具 → 导入项目 → 选择本 `minigame/` 目录；
2. AppID 换成你的小游戏 AppID（见下文「替换 AppID」）；
3. 编译后即可在工具内置模拟器里试玩；点「预览」生成二维码，手机微信扫码即可真机运行——**预览不需要审核，也不需要软著/备案**。

## 上线测试版（体验版）步骤

前提：小游戏账号已完成注册、管理员扫码登录开发者工具。

1. **替换 AppID**
   编辑 `minigame/project.config.json`，把 `touristappid` 改成你的小游戏 AppID（在 mp.weixin.qq.com 开发管理里查看）。 AppSecret 不需要——纯单机游戏无服务端调用。
2. **上传**
   开发者工具右上角「上传」→ 填版本号（如 `0.0.1`）和备注 → 确认。
   上传的是代码包，不是发布；成员体验不受影响。
3. **设为体验版**
   登录 mp.weixin.qq.com → 管理 → 版本管理 → 开发版本 → 选为体验版。
4. **添加体验成员**
   管理 → 成员管理 → 体验成员，添加测试者的微信（每个微信号都要单独添加）。
   体验成员扫码进入的是体验版，与正式版隔离。
5. **真机验证重点**
   - 触摸：所有按钮、滚动、里程碑轨道点击；
   - 节奏：12 倍速下长时间经营不卡顿；
   - 切后台/回微信再回来，暂停与恢复符合预期；
   - 存档：杀进程重进，进度不丢。

## 命令行上传（可选）

工具目录 `E:\Tencent\微信web开发者工具\cli.bat` 支持无人值守上传，但要求开发者工具处于「已登录」且开启了服务端口：

- 开发者工具 → 设置 → 安全 → 开启「服务端口」；
- 之后可执行（在仓库根目录）：

```bash
"E:\Tencent\微信web开发者工具\cli.bat" upload --project minigame -v 0.0.1 -d "小游戏移植首版"
```

若端口未开或登录态失效，命令会报连接错误——按上面 GUI 三步上传即可，效果相同。

## 正式上架的资质门槛（测试版之后的事）

测试版/体验版阶段不需要任何资质。但要**正式发布**（对公众可见、可搜索）：

| 要求 | 说明 |
| --- | --- |
| 软件著作权（或电子版权认证） | 个人可申请，约 1-3 个月；也可用电子版权认证（数日） |
| ICP 备案 | 需域名备案；小游戏类目备案与主体一致 |
| 版号 | **仅当需要内购（IAP）**。无版号不能开虚拟支付；2026 年起无版号内购会被下架。纯买断+广告变现不需要版号 |
| 流量主（广告） | 累计独立访客 UV ≥ 1000 才能开通 |

建议路径：先体验版收集反馈 → 期间准备软著/备案 → 修复后提交审核（2-7 个工作日）→ 发布买断制或广告变现版本，暂不接入内购。

## 已知边界

- canvas UI 无无障碍支持（屏幕阅读器不可用），网页版保留此能力；
- `wx.showModal` 的输入框用于公司命名/项目命名/存档导入，与网页版 prompt 行为一致；
- 音频未移植（当前版本无 BGM，不受影响）。
