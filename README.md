# 日光工作室

一个以月为回合的文字经营游戏。经营小型游戏公司，在现金、开发周期、品质与市场之间取舍。

## 运行

使用现代浏览器打开 [index.html](index.html)，无需安装依赖或启动服务器。图标与插画均在本地，不依赖在线资源。

选择类型、规模和三档投入，预览资金期限与完工时间，确认后逐月结算。完成后自动发售，可继续开发下一款。

进度自动保存到当前浏览器的本地存储。右上角可导出、导入存档或重新创业。不同浏览器、隐私模式及清理网站数据会影响存档；需要迁移时使用导出文件。

## 验证

安装 Node.js 后运行：

```powershell
node --test game.test.cjs
```

测试覆盖预览不变性、一次性投入、工资结算、品质累计、自动发售、长尾回款、危机补救、存档结构与多轮模拟。

## 首版边界

- 单项目持续经营，三种类型、三档规模和五类经营投入。
- 包含现金预警、外包补救、一次性垫资、试玩反馈与参展事件。
- 不包含多项目、部门、收购、定价、融资、复杂员工关系或技术树。
- 市场和销售是简化模型，当前数值用于验证选择是否有趣，尚未经过长期平衡或真实玩家测试。

当前实现的完整规则、参数与首版限制见 [游戏设计.md](游戏设计.md)。
