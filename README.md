# 日光工作室

一个以月为回合的文字经营游戏。经营小型游戏公司，在现金、开发周期、品质与市场之间取舍。

## 运行

使用现代浏览器打开 [index.html](index.html)，无需安装依赖或启动服务器。图标与插画均在本地，不依赖在线资源。

选择方向与规模，按需展开团队和预算；直接预览后点击下一回合，无需另行确认。研发中可付费提前测试、处理反馈，也可推进到下一决策点。完工自动发售并展示首发到账与回本情况，每月保留收支账单。

进度自动保存到当前浏览器的本地存储。右上角可导出、导入存档或重新创业。不同浏览器、隐私模式及清理网站数据会影响存档；需要迁移时使用导出文件。

## 验证

安装 Node.js 后运行：

```powershell
node --test game.test.cjs
```

测试内容见 [game.test.cjs](game.test.cjs)。
