# 日光工作室

一个持续经营的轻量游戏工作室模拟游戏。具名员工按天研发，费用按月结算，在团队、作品体验、现金与市场之间取舍。

## 运行

项目使用 [Cocos Creator 竖屏版](creator/README.md)，使用同一套界面与经营逻辑分别构建 H5、微信和抖音小游戏。

你在一间小屋里创办工作室：通过熟人招到第一位程序员，在首作教程的高亮引导下立项、验证原型、开发、试玩、改进、推广并发售。原型可以调整方向或止损，内容制作中要权衡玩法与工期；首作是练习，发售复盘会指出下一作怎么改。

程序、策划与美术分工研发，参与作品会成长并期望涨薪。赶展会或发售可以加班，但持续高压会降效，需安排休假或休整。日历展会、销量榜和年度评选提供外部反馈；好评作可开发续作，旧作可促销或制作更新。第一次回本后搬家，之后以榜单前十、年度获奖和再次扩建为中期目标。

时间可以暂停或加速，关键决策自动暂停。缺陷要靠试玩才能发现；关注人数不等于销量，首发回款也不等于最终利润。离开游戏时保持暂停，不进行离线经营。进度自动保存在本地，可在「公司」菜单导出、导入或重新创业；旧版存档读取时自动迁移。公司菜单可关闭本地音效。新版数值为试玩初值，正式平衡与广告方案仍待讨论。

## 开发与验证约定

本项目不保留自动化测试文件，后续开发（包括 AI 辅助开发）不新增或维护持久化测试脚本、测试用例或测试框架。

日常改动按需使用语法检查、浏览器试玩或微信开发者工具验证，不要求每次改动都编写测试。如确需编写测试脚本，只使用临时文件，验证结束后删除，不提交到仓库，也不留下测试专用依赖或产物。

此约定仅针对代码测试，不影响游戏内的 Demo 试玩与玩家测试机制。
