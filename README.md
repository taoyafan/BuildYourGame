# 日光工作室

一个持续经营的轻量游戏工作室模拟游戏。具名员工按天研发，费用按月结算，在团队、作品体验、现金与市场之间取舍。

## 运行

使用现代浏览器打开 [index.html](index.html)，无需安装依赖或启动服务器。图标与插画均在本地，不依赖在线资源。

为公司命名，招聘程序员，为首作选择类型与名称。开始时间后，团队会持续工作；可以暂停或加速，关键决策自动暂停。招聘、美术与素材、工具、Demo 测试、推广和发售均从工作室菜单进入。首作引导按阶段出现，后续作品继续沿用团队、工具与旧作收入，不重复教程。

普通菜单关闭后恢复打开前的运行状态；关键决策处理后需手动继续。离开页面、重新进入或导入存档均保持暂停，不进行离线经营。试玩和正式玩家评价分别记录样本；关注人数不等于销量，首发回款也不等于最终利润。

进度自动保存到当前浏览器的本地存储。右上角可导出、导入存档或重新创业。不同浏览器、隐私模式及清理网站数据会影响存档；需要迁移时使用导出文件。

旧版月度存档会迁移，保留余额、项目投入与完成比例，原存档键不删除。原团队转为具名员工，旧作剩余回款按日到账；旧版没有记录的岗位、视觉和样本信息只能作近似转换。无法识别的存档不会静默覆盖，后续保存前会保留恢复副本。当前仍以电脑验证玩法为主，手机端提供基本的一屏布局。
